Geo-tweets uses the twitter fire hose API to capture geocoded tweets - unless you pay, you only get a 1% sample, but that's still quite good. We then index all those tweets by the emojis they contain, ending up with per emoji information as to where and when they appear.

We can make this into a nice visualization if we plot this on a map of the world that moves as the world turns. Time sensitive emojis like the zzz move around the earth as different part of the planet go to bed. Beer tends to show up towards the evening - but not always!
